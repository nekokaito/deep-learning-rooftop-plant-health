# Labeling guide

Use only what is visibly supported by the photo. The initial labels are provisional:

- **Healthy**: mostly uniform, normal-looking green leaf with no obvious damage.
- **Yellowing / Discoloration**: visible yellow/pale discoloration without a dominant spot/damage pattern.
- **Leaf Spot / Browning**: distinct brown/black spots or localized browning.
- **Insect / Physical Damage**: holes, chewing marks, tears, or obvious physical damage.
- **Dry / Severe Damage**: extensive dryness, wilting, or strongly deteriorated leaf tissue.

If an image does not fit confidently, use `Uncertain` in the labels file and review it later.
