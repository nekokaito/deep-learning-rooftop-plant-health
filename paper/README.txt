OVERLEAF PROJECT: Rooftop Plant Health Classification

1. Upload this entire folder to Overleaf, or upload the ZIP file produced with it.
2. Set main.tex as the main document if Overleaf does not select it automatically.
3. The bibliography is in references.bib and uses IEEEtran style.
4. All figures used by main.tex are inside figures/.
5. The Leaf_Spot_Browning.jpg image was cropped from the supplied five-class montage because no separate leaf-spot image file was supplied.
6. The paper reports the actual baseline notebook configuration. In particular, the notebook used 1/255 rescaling, while official MobileNetV2 preprocessing maps inputs to [-1,1]. This is explicitly documented in the paper as a reproducibility point and future improvement.
7. The 46.15% test accuracy should be described as a baseline result, not as evidence of a robust general-purpose plant-health diagnostic system.
